# Report

The LaTeX source of the final report (CVPR 2026 template) and its PDF, `report.pdf`.
Build with `latexmk -pdf main.tex`; the figures in `figures/` are the ones the report includes
plus a few from the presentation (`ripe_*.png`, `restoration_triptych.png`,
`count_floor_result_ceiling.jpg`, `performance_chart.pdf`) that the report does not use.
